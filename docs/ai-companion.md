# Ask AI (prototype)

Open **Ask AI** in the island, or hold **Ctrl** while hovering over its closed trailing edge to reveal the sparkle shortcut. The double-chevron button expands the island toward the desktop midpoint; drag the bottom grip to adjust its height within that limit. Resizing follows the pointer in either direction and commits its final position without dismissing chat. The diagonal pop-out button opens a separate resizable full chat window, centered just above the taskbar on the cursor's monitor.

Opening the closed island by click, hover or its tray icon follows what you are doing. Playing music opens Music after a casual visit to another tab, including Ask AI. An unsent prompt or attachments keep your current chat ready; typing a task keeps Tasks ready too. Clicking or scrolling inside any page keeps that page for a quick return (90 seconds), and a reply arriving in the open chat starts that reading window again. Merely visiting a tab or moving the pointer does not count. After sending a prompt, AI can work in the background while the island opens Music, or Focus when only a timer is active. A new draft still takes priority while AI is working. Active phone transfers, script readings and the game readout also have relevant destinations. With music and a timer together, the island keeps Focus if that was the last page; otherwise it opens Music. With nothing active it returns to the last available page. Switching tabs leaves old drafts intact without letting them pull you away from the new page. Explicit shortcuts, reply notices and file drops always open their requested destination. Nothing switches the page while the island is already open, and automatic choices do not rewrite your saved last-page preference.

**New chat** uses the compose icon; **Temporary chat** uses the dashed speech-bubble icon. Both are icon-only buttons with hover labels. Click Temporary to enable it and show a check mark inside the icon; click again to disable it. Switching modes starts a fresh conversation when messages already exist. Your unsent draft, attachments and selected model stay with you. Leaving Temporary never saves its private messages. The circular toolbar indicator shows reply generation activity for every provider: it rotates while working, then shows ready, stopped or failed. Hover for status and elapsed time. Click while generating to stop, or click a ready indicator to read the reply. If another saved chat owns the active reply, clicking opens that chat first. The ring does not invent a completion percentage. Its animation pauses while locked, display-off, minimized or in battery saver. Daily allowance UI and account stats requests have been removed.

In **Settings → AI companion**, select OpenAI, Claude, Gemini or OpenAI Compatible. Enter and save your own API key. Completion and model-list URLs are editable; Gemini completion URLs can contain `{model}`. Select a default model from the fetched list, or enter its exact ID. Each provider remembers its own configuration and key.

No Hack Club endpoint is configured by default. For a personal Hack Club account, select OpenAI Compatible and explicitly enter:

```
Chat completion: https://ai.hackclub.com/proxy/v1/chat/completions
Model list:      https://ai.hackclub.com/proxy/v1/models
```

**Save model list**, under Settings → AI companion, is enabled by default. The first successful fetch saves the catalog on this PC, separately for each provider and scoped to its configured endpoints. Later opens and restarts reuse it without a network refresh. Click the refresh icon in model selection to update it manually. A failed refresh keeps the usable list; temporary network/server failures receive one short retry. Authentication failures and generation requests are not automatically retried. Saving an API key finishes before its model request starts. Turn Save model list off to fetch once each session. Catalog storage is bounded to 5,000 models / 16 MB per provider; endpoint URLs are represented by a hash in the saved file, and API keys are never included. Corrupt or mismatched files are ignored.

Search by model, provider or capability; searching `free` shows only models advertised as free. Results are grouped by provider. The selected model has a blue row, checkmark and **Selected** label, and the list scrolls to it when opened. Free models have a yellow dot and models supporting adjustable reasoning have a violet star, both inside the picker only. The composer shows only the model name in a compact button that fits short names and caps long ones. Image and embedding models have a type label. The configured default is the actual starting model; there is no extra “Default” entry. Hover a model for one second for a compact capability preview, or click its **info** icon for readable, scrollable details: inputs, outputs, capabilities, effort levels, context, price and description. Missing information stays labelled as unknown or not supplied. Embedding models are listed for completeness; choose a language or image model to send a chat.

The sliders icon opens filters for **Free models**, **Accepts images**, **Accepts files** and **Creates images**. Selected filters have a blue background and checkmark; a count appears on the filter button. Filters combine with each other and the search text while keeping provider groups. **Reset filters** clears them, and **Show models** returns to the matching list with its result count. Choices remain for the session. The picker has no catalog-status footer.

The composer’s compact, text-only model button opens model selection directly. Selecting a different violet-starred model uses its own default effort and closes the picker, clearing any earlier override for that newly chosen model. Selecting the already active starred model again opens the original compact slider. Drag to adjust its supported levels; release saves the setting once. Arrow keys, Home and End also work. The reset icon returns to the model default, and clicking the model name in the popup returns to the model list. Clicking outside or pressing Escape closes the slider. Models with fixed, automatic reasoning select directly without offering unsupported controls. In compact chat the wider picker opens below the island, keeping the conversation and composer visible. Expanded and full chat keep it inside their available space. Moving between the card and its picker does not collapse chat; the desktop beside the picker stays click-through. Clicking the island background, the close button or Escape dismisses the picker. Background dismissal consumes the press, so clicking above Send or an attachment control cannot also activate it. Closing the island dismisses model and attachment popovers so reopening returns to chat. Compacting a tall chat keeps it open until an actual pointer return hands it back to normal hover behavior; old pointer coordinates cannot end that handoff. Extra drawing surface is allocated only while the below-island picker is open and is released when it closes. No additional window, timer, worker, network poll or idle animation is used.

Effort controls use explicit catalog metadata where supplied, with small verified profiles for known native OpenAI, Claude and Gemini models whose list APIs omit effort details. Unknown models and budget-only thinking models do not receive guessed sliders. Compatible endpoints need to advertise `reasoning.supported_efforts`; reasoning capability alone does not imply adjustable effort. Catalog rows are cached only when the list or search changes, and slider drags save once on release. These controls add no idle polling, worker or animation.

Effort references: [OpenAI reasoning and model settings](https://developers.openai.com/api/docs/guides/latest-model), [Claude effort](https://platform.claude.com/docs/en/build-with-claude/effort), [Gemini thinking](https://ai.google.dev/gemini-api/docs/thinking), [compatible catalog effort metadata](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens), [Hack Club model catalog](https://docs.ai.hackclub.com/api/get-models.html).


The **+** menu has separate **Images** and **PDF documents** choices, with file type/size guidance, plus **Capture screen** and **Paste image**. File pickers accept only PNG, JPEG, WebP, GIF or PDF, according to the chosen action. The island stays open while a picker is active, duplicate opens are prevented, and cancellation is handled without retrying or showing an error. Picker initialization failures receive one retry; remaining failures are reported. **Ctrl+V** in the message field pastes a copied image in both the island and full chat window; text paste still works in chat and other fields. Both Windows bitmap and registered PNG clipboard formats are supported. Clipboard access happens only for an explicit paste or the existing short snipping operation. Files are sent only when you press Send. Each attachment is limited to 6 MB; up to four can be attached at once, with an 18 MB combined request-context budget. The provider and selected model decide which inputs they support. Snipping listens for the next clipboard image for at most one minute, then removes its listener. Completing a snip returns to the composer.

Choose an image model to generate images. Generated images have **Copy image**, **Download** and **Use in prompt** actions. Reuse adds the image to the composer for a follow-up instruction. OpenAI uses its image generation/edit endpoints; Gemini and compatible image-chat endpoints use multimodal chat requests. Claude accepts image/PDF inputs but cannot generate images.

Replies display native Markdown headings, bold/italic text, lists, tables, quotes, links and code blocks. Fenced code and display LaTeX (`$$…$$` or `\[…\]`) have their own **Copy** button, which stays reachable while scrolling a long block and copies its exact source. LaTeX is shown as source. Message actions appear as icons only while hovering over that message; each icon has a tooltip. **Copy as plain text** copies readable text; **Copy Markdown** preserves the original response. **Retry** resends the last user message. Enter sends; Shift+Enter adds a line. Ctrl+A and Ctrl+V work in text fields. A pending reply shows three animated dots and a stop control. The dots animate only while visible, pause when locked, the display is off or battery saver is on, and stop when a reply completes. Stopping cancels Lumo's outstanding HTTP operation; a provider may still bill work it has already completed.


**History** reopens or deletes individual chats. **Temporary** starts a conversation that is never saved; **New** starts a normal saved conversation. Settings can delete all saved chats. History and API keys are encrypted on this PC using the Windows account's DPAPI key. Nothing is uploaded until a request is sent to the configured provider. History is capped at 40 chats / 32 MB; a chat accepts 12 turns, with an explicit prompt to start a new chat instead of silently discarding context.

When a reply arrives while its chat is out of view, a quiet, clickable **AI reply ready** notice appears on the closed island, including over Music, Focus and maximized/full-screen apps. It stays available until opened or dismissed and plays no sound. Clicking opens Ask AI at that exact reply. Other notices may appear briefly; an unread AI reply returns afterward. Windows Widgets retains priority. The ready notice is static and has no expiry timer or background polling. Compacting a tall chat keeps the smaller chat open; moving back onto the compact chat and then leaving restores normal auto-close behavior. Chat and model transitions use finite animation; there is no idle AI worker, timer or network polling. History, HTTP clients and image decoding load only when used. Markdown parsing/layout is cached and bounded. A Ctrl-key observer exists only while hovering over the closed island, and is removed on leave, expansion, lock, display-off or battery saver; there is no modifier polling. No new crates or bundled models are required.

Protocol references: [OpenAI file inputs](https://developers.openai.com/api/docs/guides/file-inputs), [OpenAI image edits](https://developers.openai.com/api/reference/resources/images/methods/edit), [Claude Messages](https://platform.claude.com/docs/en/api/http/messages), [Gemini content generation](https://ai.google.dev/api/generate-content), [Hack Club image generation](https://docs.ai.hackclub.com/api/image-generation.html).
