# Lumo 2026.1110.6

- Dismiss the attachment menu when pressing outside it, consuming that press
  so it cannot also send a message or trigger another action.
- Remove AI hover text, model hover previews and empty AI/Search placeholders.
- Blink the focused text caret using the Windows setting. Edits and pointer
  placement restart the visible phase; selections hide it. One-shot wakes stop
  when editing is out of view, unfocused, locked, display-off or in battery saver.
  See [Windows caret timing](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getcaretblinktime).
- Replace section icons and labels with a vertical rail: a white bar marks the
  active section, and muted dots mark other available sections. Scroll up/down
  over the rail or click a dot to change sections. Content retains its own scroll.
- Remove the expanded island's date/time and Settings gear, including the AI
  toolbar gear. Settings remains in the notification-area icon's right-click menu.
- Update native interaction fixtures, README, AI guides and screenshots.

No new dependency, background worker, network request or closed-island timer.
Caret blinking adds one paint per Windows blink boundary only while an editor
is visibly focused; no continuous animation loop. Windows' disabled-blink setting
is respected. The rail animates only during the existing finite page transition.
The model-hover delay no longer schedules a paint. At-rest memory was not
remeasured. These are local packages; no tag or GitHub release is published.
