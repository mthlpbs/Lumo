**Calendar removed.** The Today calendar page and the Calendars section in
Settings have been removed, together with Google and Microsoft sign-in,
account management, ICS subscriptions, meeting links and calendar sync.

Older profiles that opened Today now open Music. Existing settings and other
features, including the optional AI companion, remain usable. The date and
clock in the island header remain available.

Calendar workers, OAuth build configuration and unused Windows calendar
bindings have been removed. Nothing new runs at rest or on each frame.
