# Lumo 2026.1109.6

- Add optional Windows services to Search, with state, explicit Start/Stop
  buttons and context-menu controls. Windows handles administrator permission
  when needed. Startup types and dependent services are not changed.
- Discover installed PowerToys module settings and activate running enabled
  tools through PowerToys' own local events.
- Find commands in open VS Code windows, direct VS Code setting links and
  supported browser settings pages. Add up to 16 saved app actions with a
  name, target, arguments and search keywords.
- Add opt-in Chrome/Edge/Brave bookmarks and accessible open browser tabs.
  Bookmarks retain their browser profile; tabs are selected by their live
  window, process, UI Automation runtime ID and title. No browser extension
  or debugging port is needed. Firefox tabs/settings are supported; its
  bookmarks are not indexed.
- Add independent Settings toggles and Refresh search sources. Update README,
  Search documentation and privacy disclosures.

No new crates or permanent workers, polls or timers. One short-lived discovery
worker runs on Search open or refresh, with cancellation and bounded source
sizes. UI Automation is loaded only when browser-content search needs it.
Explicit actions use one short-lived worker; service status is not polled.
An action failure can use Lumo's existing finite notification mechanism.

These are local Windows x64 packages. No GitHub release has been published.

Validation: 583 regular Rust tests and 12 version/workflow checks passed.
Native checks covered independent Settings toggles, saved actions, compact
service rows and Stop-command dispatch, rejecting a service action after its
source was disabled, read-only Windows service enumeration, installed browser
and VS Code discovery, local bookmark parsing, and tab discovery/selection in
an isolated Lumo-owned window using real UI Automation runtime IDs. No personal
browser tab was selected and no actual service was started or stopped during
these checks. Documentation screenshots and their content hashes were checked.

Service button identity includes the service name and operation, so a result
refresh cannot redirect a click or turn a pending Stop click into Start. The
native regression check exercises that state change without controlling any
real service.
