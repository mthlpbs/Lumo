# Lumo 2026.1112.2

## Changes

- Click the Ask AI title for a provider dropdown with the native Ask AI chat, ChatGPT, Gemini, Claude, Muse (`muse.ai`) and Perplexity AI. Each website has its identification mark.
- Website mode fills the island or detached window, with its provider selector, Keep open, Resume page, mini-window/return and Close controls overlaid at the top right. Native chat controls and the address bar are absent in this mode.
- AI websites share Lumo's existing SearchWeb browser profile, cookies and site storage. Window handoff reparents the same controller, preserving its page and draft. Website-owned dialogs do not dismiss the workspace, and native chat drafts remain separate.
- Recognized response layouts can show the same persistent reply-ready notice and bounded preview as native Ask AI. Detection observes an explicitly submitted response without polling; unknown markup produces no false completion claim. Website logins and signed-in service behavior have not been live-tested.
- Hidden in-flight requests retain their last full viewport. Idle hidden pages suspend or close according to Resume, and lock, display-off, battery saver and minimizing put the page to rest. No browser starts before a website is selected.

## Validation and cost

- 618 workspace tests passed, plus 12 native GPU/software checks covering all five response adapters, automatic script registration, shared cookies with an isolated fictional cookie, actual full-client screen pixels, both window hosts, owned dialogs, native drafts, viewport retention, ready notices and suspension.
- Existing native chat, composer, diagonal resize and embedded browser regressions passed in both renderers. No test prompt or login was sent to an AI service.
- No new crate or bundled browser engine. Five small vector paths use the existing cached icon renderer. No startup worker, idle poll or new Lumo animation loop; an explicitly submitted website request has one bounded startup deadline that is canceled when generation is observed.
- Memory at rest was not remeasured.
