# Lumo 2026.1109.8

- Combine browser navigation, default-browser, mini-browser, pin and resume
  controls inside one address bar. Narrow mini windows use a native overflow
  menu to keep room for the title.
- Show the webpage title while browsing. Clicking the field or pressing Ctrl+L
  reveals the full URL and hides every icon. Double-click selects the entire
  URL, including slashes. Escape cancels mini-browser editing before closing it.
- Extend opt-in Google suggestions to address-bar search text. Website
  addresses are excluded. Dropdowns cover native webpage pixels without
  resizing the page or exposing the desktop. Loading stays within the rounded
  address field at every tested display scale.
- Remove the launcher browser button and blue search-field border. Ctrl+Enter
  provides an explicit web action even when local matches exist.
- Add dark, rounded native result menus with accessible names, keyboard
  navigation and appropriate actions for each result. Apps offer Open,
  administrator activation where supported, Copy path/app link, Copy icon file
  and Copy icon image. Frequent results can be removed individually.
- Export ICO files for pasting in Explorer, or PNG/Windows bitmap image formats
  for image pasting. Icon work runs only after an explicit menu action; at most
  32 generated icon files are retained.
- Update README, Search documentation, privacy information and native captures.

No new dependencies or idle work. Page titles use WebView2 notifications.
Native menu hooks exist only while a menu is open. Icon copying uses a
short-lived worker. Suggestions reuse the bounded, cancelable debounce path
and stop when editing ends or the session is away.

These are local Windows x64 packages. No GitHub release has been published.
