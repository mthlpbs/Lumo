The embedded web browser now uses a macOS-inspired toolbar: standard back and
forward chevrons, a centered compact site address, a full editable address/search
field, refresh/stop, and a labeled Open in browser action. The external action
uses the current page URL, including redirects and links followed after searching.

Loading appears as a thin progress line inside the address field, driven by real
WebView2 navigation milestones. Typing no longer closes the current page or makes
requests; Enter explicitly opens a URL or searches with the selected provider.
Page failures offer retry, and HTTP remains visibly distinguishable from HTTPS.
Ctrl+L edits the full URL, Ctrl+R/F5 reloads, Alt+Left/Right navigates history,
and Tab moves from the address field into the page. Back returns to local search
when there is no earlier web page.

Webpages now sit inside an inset, rounded viewport with native clipping for both
pixels and input. The GPU and software rendering paths keep the same island
surface, click handling, horizontal close gestures and collapse behavior. Browser
focus notifications restore address editing after clicking inside the webpage.
Closing during startup is safe even when native controller completion callbacks
arrive synchronously; close/placement APIs release shared state before reentry.

Validation: 575 Rust tests and 13 packaging/workflow tests passed. Explicit native
checks cover real loopback navigation/loading/history/reload/stop/error recovery,
editing without destroying the page, rounded native hit regions, browser input
through both GPU and software renderers, both themes, ordinary page gestures,
local search, application icons and native Windows context menus. Live visual QA
also rendered the public Google query from the reported example in an isolated
browser profile. Native captures were inspected in Classic and Pill.

No new crate, background poll or idle timer was added. Navigation callbacks redraw
only on browser events; there is no animated or timed loading bar. The rounded
child host exists only while web browsing is open, and closes with the controller.
While this page is drawn, the toolbar, viewport outline and four corner masks are
painted with the existing frame; there is no added work on closed-island frames.
Browser engine and loader packaging remain unchanged.

Package metadata, aligned versions, four checksums, exact portable contents and
byte-identical extracted installer payloads were verified.
