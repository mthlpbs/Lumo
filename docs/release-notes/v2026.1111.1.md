# Lumo 2026.1111.1

## Changes

- Search results now scroll in pixels, preserving small touchpad movements and smoothly easing wheel input. Wheel movement leaves keyboard selection in place. Keyboard navigation reveals the selected result, and clipped rows receive input only inside the result viewport.
- Phone Drop now uses only the local network. Internet pairing controls, commands, event handling and the Windows pairing service have been removed. Previously saved pairing secrets remain inactive and are never loaded by the app.
- Redesigned the desktop panel around the receiving PC, a larger QR code, address choices and clear approval and transfer states. IP is the default. PC-name QR links preserve the same session secret and port and depend on the network resolving that name. Copy link includes the full secret session address.
- Redesigned the phone page with a destination device, keyboard-accessible file selection, separate send/save areas, native accessible progress and light/dark appearance. No external assets or scripts are loaded.
- QR codes preserve four white modules on each side, including long PC-name addresses at different display scales.
- README screenshots, current instructions and privacy notes are updated. Earlier pairing/server guides are marked historical.

## Validation

- 614 workspace tests passed, including fractional scroll settling, keyboard reveal, address generation and QR scan margins.
- Four native checks passed per renderer, covering the new six-state Phone Drop layouts in both themes, Search rendering and keyboard actions, mouse/touchpad routing and outside-click dismissal.
- The phone page passed headless Chromium checks in light and dark appearance at 320, 390 and 768 pixels. Keyboard file selection, approval/upload, completion, touch-target sizes and JavaScript errors were checked using local fixtures.
- Live phone transfer and PC-name resolution on a physical Wi-Fi network were not tested. Core local-server transfer tests passed.

## Resource cost

No new crate, background worker, idle poll or network request. The internet pairing worker and its request path are removed. Search requests frames only during a short user-driven scroll and snaps in battery saver. The existing Phone Drop server runs only during an open session. QR images are cached and rebuilt only when the selected link or display scale changes.

Memory at rest was not remeasured.
