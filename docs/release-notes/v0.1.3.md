**Apple Music's own lyrics (optional):** with an Apple Music subscription, Lumo can show the synced lyrics the Apple Music app shows, whichever app is playing. Right-click the island, then **Apple Music lyrics › Use token from clipboard**; the [README](https://github.com/lucacadalora/lumo#apple-music-lyrics) explains how to copy the token from the web player. LRCLIB stays the default and the backup.

**Better lyrics for YouTube:** songs playing in a browser tab find synced lyrics more often, and the island names the site (YouTube, YouTube Music) instead of the browser. When a music video runs much longer than the song, its lyrics show unsynced instead of out of step.

**Also:** lyrics skip one-line placeholder entries, and keep looking for a synced copy when the first answer is plain text only.

**Install:** download `Oyen-Lumo-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Lumo\lumo.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Lumo`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
