# Lumo 2026.1109.3

- Open the current web page in a draggable, resizable mini browser that stays
  on top, like the mini music player. The return icon moves it back into the
  island with the same page, history and scroll position.
- Keep using local app search and the island's other pages while browsing in
  the mini window. Explicit web searches use that window while it is open.
- Fix thin see-through seams around rounded webpages by aligning the native
  page and its cutout to physical pixels and keeping a solid edge seal.
- Loading progress now fills the entire address field behind its text and
  controls. It uses real navigation events and stops when loading finishes.

No new dependencies, background workers, timers or browser instances. The
extra window and its static renderer are created only when selected and are
released on return or close. Its chrome does not redraw at rest. The page
rests while locked, the display is off, Widgets is open or battery saver is on.

Local package costs compared with 2026.1109.2:

- Installer: 4,258,167 bytes (+5,723 bytes).
- Portable ZIP: 3,054,176 bytes (+7,007 bytes).
- Executable: 6,241,792 bytes (+16,384 bytes).
- At-rest memory was not remeasured for this local build.

Validation: 575 regular Rust tests and 12 version/workflow tests passed. Native
browser checks passed with GPU and software rendering, covering page handoff,
real native button input, full-field loading progress, idle repainting and
opaque page-edge coverage at 100%, 125%, 150% and 200% scaling. Installer
extraction and portable payload checks passed.

These are local Windows x64 packages. No GitHub release has been published.
