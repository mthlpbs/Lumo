Search now shows native Windows app/file icons with their correct shapes and
transparency. The result list has no filter chips, repeated subtitles, count
footer, footer gear or selected-row Open label. Lumo actions and preference
pages have been removed from results; Windows Settings destinations remain.

Matching uses names and explicit Windows Settings keywords, with a clear empty
state for unmatched queries. The opening list contains frequently opened
results, with individual removal and a clear-history control. Query text is
not saved. Deleted files and removed locations are revalidated before showing
frequent file suggestions.

Settings > Search can enable filename/folder search in up to 16 chosen
locations. Searches are debounced, cancellable and bounded, and do not traverse
junctions or run an indexer. Right-click results for Windows Shell menus,
including administrator/different-user actions where supported, Properties,
Copy as path and installed Shell extensions.

Optional Bing, Google, DuckDuckGo or Brave search opens inside the island using
the installed Edge WebView2 Runtime. No engine is bundled. Microsoft's small
loader is included beside the EXE and loaded only on explicit web use. The
browser and its gesture hook close with Search; battery saver pauses web/file
work. Horizontal swipes still open/collapse Search and preserve normal page
navigation.

Validation: 574 Rust tests and 13 packaging/workflow tests passed. Explicit
Windows desktop checks cover native icons in Classic/Pill, empty results,
frequent suggestions, settings, context-menu administrator verbs, normal page
swipes, gesture inertia, and the installed WebView2 Runtime. A screen-pixel and
hit-testing check verifies web content is visible and receives input inside
the island on both GPU and software rendering; a browser swipe closes it.

Resource cost: the stripped EXE is 6,212,608 bytes (+120,832 from 2026.1108.5).
The portable ZIP is 3,038,059 bytes (+135,496) and the setup download is
4,248,007 bytes (+100,965).
Microsoft's verified x64 loader is 165,336 bytes. New dependencies are
webview2-com/sys 0.33.0 (compatible with the existing windows 0.58 APIs), their
build-time callback macro, and build-time thiserror 1. They provide typed COM
callbacks for the installed shared Runtime and are built for size. No browser
engine, permanent worker or idle polling is added; the loader is absent from
startup imports and the cold-idle module list.

Both versions were built with release stripping disabled for symbol analysis.
PE/COFF nm sizes are zero, so its demangled addresses were mapped to exact PE
unwind ranges. Text grew from 5,200,896 to 5,306,880 bytes (+105,984).
Attributed WebView2 wrapper functions account for 2,964 bytes; inlined methods
are counted with their containing functions. Per-crate totals are recorded in
`.tools/search-size-cost.json` with the before/after nm listings.
