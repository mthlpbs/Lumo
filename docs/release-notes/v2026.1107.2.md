**Updates in Settings > About.** Check for a newer version, download it,
and install it with a restart without leaving Lumo.

**Automatically update Lumo** downloads verified updates and installs them
on the next launch. **Tell me about new versions** controls notifications
separately. Both switches are off by default; manual checks always work.

About now shows checking, download, ready, and retry states. The data-folder
and release-note links have been removed. Background checks rest while the
session is locked, the display is off, or battery saver is on.

Install `Lumo-Setup-2026.1107.2.exe`, or extract
`Lumo-2026.1107.2-portable.zip` and run `Lumo/lumo.exe`.
