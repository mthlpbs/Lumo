# Lumo 2026.1110.1

- Move AI out of the normal island tabs. A left horizontal scroll on the
  closed island opens AI; right scroll opens Search. Each gesture fires once,
  and the directions have independent settings. Ordinary clicks keep their
  music/timer/page routing.
- Replace the compact AI page with a tall 560 × 680-DIP workspace, constrained
  to the screen. Show the full conversation, a multiline composer with a
  separate attachment/model row, and a compact toolbar for history, new and
  temporary chats, pin, resume, mini window, settings and close.
- Add a freely resizable, always-on-top AI mini window. Moving into it and
  returning preserves the chat, draft, attachments, model and reading position.
  Remember its size and provide a size reset in AI Settings. Close dismisses
  the window; returning to the island has its own icon.
- Add separate Keep open and Resume chat preferences, both off by default.
  Unpinned AI closes on outside activation. Resume preserves in-session state;
  otherwise reopening starts a fresh chat while normal saved history remains.
  Closing with Resume off immediately releases unsent attachment/image buffers.
- Add local history-title filtering, draft-only prompt starters, a Latest reply
  shortcut, and a disabled Send state for empty messages. Keep existing Markdown,
  code-copy, attachments, provider selection and reasoning controls.
- Add Ctrl+N, Ctrl+Shift+N, Ctrl+H and Ctrl+K for new chat, temporary chat,
  history and model selection in either host. Mini handoff focuses the composer.
  Unconfigured workspaces offer a direct Connect a provider action.
- Preserve outside dismissal through nested native focus changes. Explicit AI
  openings remain visible over fullscreen apps; closing restores the ordinary
  fullscreen visibility policy. Ordinary pages do not reserve AI's tall layout.
- Hide the mini window and stop its animation timers while locked, display-off,
  in battery saver or while Widgets is open. Restore it without stealing focus.
- Update README, AI/Search help, privacy information and native UI captures.

No new dependencies, idle workers or polling. The mini renderer exists only
while open. Visible generation uses the existing finite/event-driven paint
paths; provider requests and explicit attachment access retain their existing
behavior. At-rest memory was not remeasured for this local build.

These are local Windows x64 packages. No tag or GitHub release is published.

Validation: 593 regular Rust tests passed. Thirteen native checks cover gesture
direction and inertia, workspace/mini handoff, pin/resume, away-state hiding,
draft-only starters, local history filtering, minimum window size at four
display scales, model selection and reasoning, Markdown/code copy, keyboard
input, notifications, disabling AI, Settings, Search outside dismissal and the
embedded browser. Workspace and companion checks also pass with the software
renderer. Fixtures use offline conversations and perform no provider message
request, administrator action, service operation or clipboard replacement.
