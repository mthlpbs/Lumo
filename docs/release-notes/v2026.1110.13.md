  Remove the Battery view, and remove FPS/temperature from compact Performance.

  Give Network separate download/upload labels, rates and quiet color cues.

  and its devices, with no repeating wakeups. Compact sampling also rests on
  lock, display-off, battery saver, full-screen hiding, notices and other pages.
  Queued readings are ignored once their view is hidden.

existing System worker samples once per second only while a visible System,
compact or enabled game view needs it. Compact values redraw on incoming events;
the display frame clock parks between interactions. On Time the System worker
blocks and its sampler is released. At-rest memory was not remeasured.
