File and folder search has been removed completely, including custom-location
controls, configuration fields, result types, pickers, scanning workers and
the debounce timer. Old file-result counts are filtered from the loaded
history. Applications, Windows Settings, frequent results and optional web
search remain available.

The no-match view now fits a compact 204-DIP island when web search is enabled.
A short status sits above one clear action card with a globe, the selected
provider, a query preview and a right arrow. Click or Enter opens web results
inside the island. Without web search, the smaller empty view suggests trying
another name. Lists resize to fit up to five rows; late result changes get a
final layout frame before the frame clock parks. Web navigation now uses a
proper back arrow rather than a media rewind icon.

Validation: 574 Rust tests and 13 packaging/workflow tests passed. Explicit
Windows checks cover Classic and Pill captures, empty-state height and action
hit bounds, settings, native administrator context-menu verbs, opening/closing
gestures, normal page navigation and embedded WebView2 rendering/input. Older
file preferences are ignored without resetting the web provider, and retired
file history is removed without affecting application history. EXE/installer
versions, installer payloads, portable contents and checksums were verified.

No new crate or idle work was added. The file worker, picker and typing timer
were removed; the small new globe/arrow vectors load only when drawn. The
existing optional WebView2 runtime and loader behavior are unchanged.

A five-second CPU-cycle sample at rest measured 73.6 MiB private memory,
96.9 MiB working set, 3.20 million processor cycles/s and 28.8 wake-ups/s.
Most wake-ups came from the existing system sampler. The repository's broader
memory/CPU budgets still fail, as they did before this change; budgets were
not raised. These single-machine samples are not a statistical benchmark.
The raw report is `.tools/weight-search-v3/weight.json` in the local workspace.
