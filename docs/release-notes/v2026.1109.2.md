# Lumo 2026.1109.2

- Music now uses a mini player icon to open the separate lyrics player. A
  matching exit mini player icon returns to Music from either surface.
- The mini player's return control stays visible without hovering; its tooltip
  says "Exit mini player". The former dot-to-close hover animation is removed.
- Search uses compact rows, smaller native app icons, and an inset selection
  marker. The island fits the result count, including a single match.
- The globe beside local search opens the selected web engine inside the island.
  Pin and resume controls appear only in the browser.
- The README describes the current controls and includes refreshed screenshots.

No new dependencies, background workers, timers, or network activity at rest.
The icon changes use cached vector paths and add no repeating animation.

Local package costs compared with 2026.1109.1:

- Installer: 4,252,444 bytes (+217 bytes).
- Portable ZIP: 3,047,169 bytes (+3,544 bytes).
- Executable: 6,225,408 bytes (+1,536 bytes).
- At-rest memory was not remeasured for this local build.

Validation: 575 regular Rust tests, 12 version/workflow tests, two mini player
desktop checks, and 112 graphical states across Classic and Pill passed.
Installer extraction and portable payload checks passed.

These are local Windows x64 packages. No GitHub release has been published.
