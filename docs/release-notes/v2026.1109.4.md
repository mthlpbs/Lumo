# Lumo 2026.1109.4

- Search and the embedded browser no longer show a close button. Escape and
  horizontal swipe still close them.
- Browser opening keeps Search's width and expands only its height by default.
  A short header crossfade accompanies the height transition.
- Settings > Search offers Tall/Wide layout, browser height presets, and
  desktop-site fitting. Desktop fitting preserves the Windows desktop user
  agent and fits a desktop-width page into the tall window.
- Browser actions use icons, including Open in browser. Narrow windows use a
  full-width address field with navigation controls on a second row.
- Resize the mini browser freely down to 280 × 200 DIPs. Arbitrary dimensions
  are remembered, with a reset available in Settings.
- Optional Google suggestions appear only when local search finds nothing.
  They are off by default, use a 350-ms typing debounce, show up to four items
  and support keyboard selection. Enabling them sends unmatched text to Google.

No new dependencies or permanent background work. Suggestions create one
short-lived request worker only while opted in and viewing unmatched local
search. Requests are bounded, cancelable and stopped on close, setting changes,
lock, display-off and battery saver. The transition runs only while opening.

These are local Windows x64 packages. No GitHub release has been published.

Validation: 578 regular Rust tests and 12 version/workflow tests passed. Native
checks covered the unchanged tall-browser width, desktop viewport and Windows
user agent, arbitrary mini-window sizing and restoration, GPU/software rendering,
opaque page-edge coverage at 100%, 125%, 150% and 200% scaling, full-field loading
progress, suggestions selection and cancellation, and browser preferences. A
live Google suggestions request also passed. Documentation images were checked
against their content hashes.

Local package costs compared with 2026.1109.3:

- Installer: 4,267,862 bytes (+9,695 bytes).
- Portable ZIP: 3,066,771 bytes (+12,595 bytes).
- Executable: 6,278,144 bytes (+36,352 bytes).
- At-rest memory was not remeasured for this local build.

Installer extraction, executable metadata, portable payload and SHA-256 checks
passed. No new work runs at rest. Opening uses a finite 220-ms header fade;
suggestions add one debounce wake and a bounded request only when enabled and
an unmatched query is visible.
