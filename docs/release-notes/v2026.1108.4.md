**A command launcher for Lumo.** Horizontal scrolling in either direction over
the island or Settings opens Search. Find installed desktop and Microsoft
Store applications, Lumo actions, and Lumo or Windows settings. Arrow keys
select, Enter opens, and Esc or a click outside dismisses it.

The new Settings > Search section controls the opening gesture and searchable
sources, and can refresh the installed-app catalog. Turning the gesture off
restores horizontal page switching. Vertical header scrolling still changes
pages. Disabled add-ons and their settings stay out of search results.

App discovery runs on demand using a bounded Windows Shell worker; it stops
when dismissed or suspended. No background indexer, network search, permanent
thread, new dependency or idle animation is introduced.
