**Search now lives inside the dynamic island.** Swipe either direction over
the closed island to expand its width and height into Search. Swipe again
anywhere over Search to collapse it. Inertia cannot toggle it twice. Open
island pages and Settings keep their original horizontal navigation.

The layout now follows Classic and Pill, with a capsule search field, compact
filters, five result rows, keyboard navigation and a collapse control. Installed
desktop and Store apps show their actual Windows icons. The previous separate
Search popup and its graphics device have been removed.

Icons load for visible apps only, with a bounded 64-icon cache and cancellable,
short-lived work. No new dependency, polling timer or idle animation is added.
Search settings, source controls and local-only queries remain available.

Local validation: 570 Rust tests, six explicit Windows desktop checks and
12 packaging/workflow tests passed. The desktop checks cover both themes,
real Windows app icons, width/height animation, gesture inertia, ordinary page
swipes, keyboard selection, empty results, settings access and dismissal.

Cost compared with 2026.1108.4: EXE 6,091,776 bytes (+12,800), portable ZIP
2,902,563 bytes (+5,946), installer 4,147,042 bytes (+3,325). No new crate,
permanent thread, polling timer or idle frame work. Icons are loaded only
while Search is open and retained in a bounded cache (up to 576 KiB of pixels).

Performance probe: the previous build already exceeded the local budgets
(71.7 MiB private / 90.4 MiB working set and 3.33 million processor cycles/s
at rest). The new build's sampling period included repeated expand/collapse
interactions in its log, so its 87 MiB private / 120.6 MiB working set and
575.94 million cycles/s are **not a valid idle comparison**. The performance
budget check did not pass; a quiet desktop run is still needed. Budgets were
not changed. Raw reports are in `.tools/weight-inline-before/` and
`.tools/weight-inline-after/` in the local workspace.
