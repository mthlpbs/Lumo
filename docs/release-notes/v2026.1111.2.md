# Lumo 2026.1111.2

## Changes

- Incoming Phone Drop files now save directly in Windows Downloads. Settings > General > Phone Drop offers Change folder and Use Downloads. New sessions use the selected folder, while transfers already in progress keep their destination and existing received-file paths remain usable.
- Removed the PC-name address option, its QR generation and switching controls. Phone Drop uses the local IP QR code and Copy link.
- Added optional focus-completion edge lighting. An island halo appears first, then two light trails travel around the display edges and gradually fade to full transparency in 3.6 seconds.
- Settings > Focus > Completion lighting offers Windows accent, Blue, Mint, Rose, Gold and Violet, plus Preview. Preview works with automatic lighting switched off. Automatic lighting defaults to off so it can be tested before enabling.
- Effect windows pass mouse input through and never activate, preserving the foreground application and keyboard focus. The effect ends and releases its resources while locked, display-off, battery saver, or hidden for full-screen content. Break completion and stale focus completions after sleep do not trigger it.
- README, privacy notes and Phone Drop screenshot updated.

## Validation

- 615 workspace tests passed, including receive-folder defaults and resets, travel/fade lifetime, and premultiplied transparency.
- Native checks verify input transparency, preserved foreground focus and destruction of every effect window. Effect fixtures use off-screen windows and composite only their own bitmaps, without capturing desktop or personal application pixels.
- Native Settings checks exercise Preview while disabled, color selection, receive-folder selection commands and resetting to Downloads. App checks cover actual focus completion, preview, break completion, stale deadlines, lock, display-off and battery saver.
- Phone Drop fixtures verify the local-IP-only layout in Classic and Pill. Nine native checks passed across the GPU and software renderer paths, including existing Settings regressions.

## Resource cost

No new crate, background thread, network request, or timer. The existing frame clock draws the finite effect near 30 Hz. Four narrow edge DIBs and one island halo are allocated only on request and released after completion or suspension. Pixel work is limited to those surfaces, and unlit edge segments stay hidden without repainting. The setting itself performs no work at rest. Folder selection reuses the existing short-lived native picker.

Memory at rest was not remeasured. Physical-phone transfers were not retested for this change.
