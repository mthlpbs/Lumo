# Provider marks

These small monochrome SVG paths use the existing native icon renderer. They
are parsed and cached only when first drawn. No image downloads or raster
decoder are needed at runtime.

ChatGPT/OpenAI, Gemini, Claude and Perplexity marks come from Simple Icons
14.0.0 (CC0-1.0):

- https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/openai.svg
- https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/googlegemini.svg
- https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/claude.svg
- https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/perplexity.svg
- License: https://github.com/simple-icons/simple-icons/blob/14.0.0/LICENSE.md

Muse's mark comes from Meta's Muse site:
https://muse.ai/images/landing/brand/muse-logo.svg
Its cubic path coordinates are uniformly scaled from a 100-unit viewBox to
24 units. The menu uses its blue brand color rather than the source gradient.

Only the path geometry is included; the marks identify their respective sites
and do not indicate endorsement. All trademarks belong to their owners.
